Ashish Kujur — subtle website refresh

Open index.html in a web browser to preview the complete site.
To apply the refresh, replace these five files in your existing repository:
index.html, research.html, teaching.html, cv.html, style.css.
photo.jpg and favicon.svg are unchanged and are included for offline preview.

The refresh keeps all existing text, links, and page order. It changes the
typography, spacing, colors, photo framing, and list styling. Navigation marks
the current page; CV dates stack below the text on narrow screens. A keyboard
skip link and a main landmark have been added to each page.

There are no new dependencies, build steps, or scripts in the website.
The existing Google Fonts resource is retained; system fonts provide a fallback.

Validation: original page text and URLs preserved, internal assets present,
current-page indicators checked, and text contrast verified. Browser rendering
and mobile interaction could not be tested in this environment.

These changes have not been pushed to GitHub or published.
